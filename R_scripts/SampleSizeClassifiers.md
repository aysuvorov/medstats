

## Расчёт размера выборки для оценки AUC с заданной мощностью и контролем ошибки I рода при известной распространённости исхода

### 1. Постановка задачи и обозначения

Рассматривается задача планирования исследования, в котором качество бинарного классификатора оценивается площадью под ROC-кривой (AUC). Необходимо определить минимальный общий объём выборки \(N\), обеспечивающий заданную мощность \(1-\beta\) при односторонней проверке гипотезы о том, что истинное значение AUC превышает заранее установленный порог \(\theta_0\), в то время как ожидаемое значение AUC равно \(\theta_1 > \theta_0\). Доля положительных исходов (распространённость) \(p = \text{prev}\) предполагается известной и не изменяется в ходе набора данных.

Введём следующие обозначения:

\begin{align*}
\theta_1 &\; \text{— ожидаемое (истинное) значение AUC (целевая точечная оценка)}, \\
\theta_0 &\; \text{— пороговое значение AUC, ниже которого классификатор считается неприемлемым}, \\
\delta &= \theta_1 - \theta_0 \quad \text{— минимальная клинически значимая разница (величина эффекта)}, \\
\alpha  &\; \text{— допустимая вероятность ошибки I рода (уровень значимости)}, \\
1-\beta &\; \text{— требуемая мощность (вероятность отклонить } H_0 \text{, когда } \theta = \theta_1), \\
p       &\; \text{— распространённость положительного класса } (0 < p < 1), \\
N       &\; \text{— общий размер выборки}, \\
n_1     &= p N \quad \text{— число случаев (положительный класс)}, \\
n_0     &= (1-p) N \quad \text{— число контролей (отрицательный класс)}.
\end{align*}

Формально проверяется следующая односторонняя гипотеза:

\[
H_0: \text{AUC} = \theta_0 \quad \text{против} \quad H_1: \text{AUC} = \theta_1 > \theta_0.
\]

### 2. Оценка дисперсии AUC

Для непараметрической оценки AUC по ограниченной выборке используется формула дисперсии, предложенная Hanley и McNeil (1982) [1]. При альтернативной гипотезе (истинное значение \(\theta_1\)) дисперсия \(\hat{\theta}\) задаётся выражением:

\[
V(\hat{\theta}) = \frac{1}{n_1 n_0}\Bigl[
\theta_1(1-\theta_1) + (n_1-1)(Q_1 - \theta_1^2) + (n_0-1)(Q_2 - \theta_1^2)
\Bigr],
\]

где вспомогательные величины \(Q_1\) и \(Q_2\) зависят только от \(\theta_1\):

\[
Q_1 = \frac{\theta_1}{2-\theta_1}, \qquad
Q_2 = \frac{2\theta_1^2}{1+\theta_1}.
\]

Данная аппроксимация справедлива при отсутствии предположений о бинормальности распределений и широко используется при планировании диагностических исследований [2,3].

### 3. Уравнение мощности и определение \(N\)

При достаточно больших \(n_1\) и \(n_0\) распределение оценки AUC приближённо нормально со средним \(\theta_1\) и дисперсией \(V(\hat{\theta})\). Тогда условие достижения мощности \(1-\beta\) записывается в виде:

\[
\delta = \theta_1 - \theta_0 = (z_{\alpha} + z_{\beta})\,\sqrt{V(\hat{\theta})},
\]

где \(z_{\alpha} = \Phi^{-1}(1-\alpha)\) и \(z_{\beta} = \Phi^{-1}(1-\beta)\) — квантили стандартного нормального распределения.

Подставляя выражение для дисперсии и выражая \(n_1, n_0\) через общий размер выборки \(N\) и распространённость \(p\), получаем уравнение относительно \(N\):

\[
\delta^2 = (z_{\alpha} + z_{\beta})^2\,
\frac{1}{pN \cdot (1-p)N}\Bigl[
\theta_1(1-\theta_1) + (pN-1)(Q_1 - \theta_1^2) + \bigl((1-p)N-1\bigr)(Q_2 - \theta_1^2)
\Bigr].
\]

После упрощения уравнение может быть записано в виде \(F(N) = 0\), где

\[
F(N) = V\bigl(N; \theta_1, p\bigr) \cdot (z_{\alpha} + z_{\beta})^2 - \delta^2.
\]

Общий размер выборки \(N\) находится численно как корень этого уравнения на интервале \([1, N_{\max}]\); в прилагаемой реализации используется метод бисекции (uniroot). Поскольку функция \(F(N)\) монотонно убывает по \(N\), решение единственно.

### 4. Вычисление численностей групп

После определения \(N\) рассчитываются необходимые размеры групп:

\[
n_1 = \lceil p N \rceil \quad \text{(число случаев, положительный класс)},
\]
\[
n_0 = \lceil (1-p) N \rceil \quad \text{(число контролей, отрицательный класс)}.
\]

При необходимости округления вверх гарантируется, что итоговая мощность будет не ниже заданной. В рамках описанной методологии дисперсия оценивается при альтернативном значении \(\theta_1\), что является стандартной практикой планирования размера выборки для AUC [2,4].

### 5. Программная реализация

Описанный алгоритм реализован в виде функции `sample_size_AUC` (приведена в приложении), позволяющей вычислять любой из параметров — \(N\), \(\delta\), мощность или уровень значимости — при фиксированных остальных. Функция полностью воспроизводит приведённые выше формулы и использует дисперсию Hanley–McNeil с непосредственным учётом распространённости \(p\).

**Литература**

1. Hanley JA, McNeil BJ. The meaning and use of the area under a receiver operating characteristic (ROC) curve. *Radiology*. 1982;143(1):29-36. doi:10.1148/radiology.143.1.7063747  
2. Obuchowski NA. Sample size calculations in studies of test accuracy. *Stat Methods Med Res*. 1998;7(4):371-392. doi:10.1177/096228029800700405  
3. Obuchowski NA, McClish DK. Sample size determination for diagnostic accuracy studies involving binormal ROC curve indices. *Stat Med*. 1997;16(13):1529-1542. doi:10.1002/(SICI)1097-0258(19970715)16:13<1529::AID-SIM565>3.0.CO;2-E  
4. Zhou XH, Obuchowski NA, McClish DK. *Statistical Methods in Diagnostic Medicine*. 2nd ed. Hoboken, NJ: Wiley; 2011.

```
sample_size_AUC <- function(AUC = NULL, delta = NULL, n = NULL, sig.level = 0.05,
                         power = NULL, prev = NULL, NMAX = 1e4){
  if(sum(sapply(list(n, delta, sig.level, power), is.null)) != 1) 
    stop("exactly one of 'n', 'delta', 'sig.level', and 'power' must be NULL")
  if(!is.null(AUC) && any(0.5 >= AUC | AUC > 1))
    stop("'AUC' must be numeric in (0.5, 1]")
  if(!is.null(delta) && !is.numeric(delta) || any(0 > delta | delta > 1))
    stop("'delta' must be numeric in [0, 1]")
  if(!is.null(sig.level) && !is.numeric(sig.level) || any(0 > sig.level | sig.level > 1)) 
    stop("'sig.level' must be numeric in [0, 1]")
  if(!is.null(power) && !is.numeric(power) || any(0 > power | power > 1))
    stop("'power' must be numeric in [0, 1]")
  if(!is.null(prev) && !is.numeric(prev) || any(0 > prev | prev > 1))
    stop("'prev' must be numeric in [0, 1]")

  if(is.null(prev)) prev <- 0.5

  if(!is.null(delta)){
    AUC.delta <- AUC - delta
    if(!is.null(AUC.delta) && !is.numeric(AUC.delta) || any(0 > AUC.delta | AUC.delta > 1))
      stop("'AUC'-'delta' must be numeric in [0, 1]")    
  }

  ## variance from Hanley and McNeil (1982)  
  Varfun <- function(N, AUC, prev){
    n <- prev*N
    m <- (1-prev)*N
    Q1 <- AUC/(2 - AUC)
    Q2 <- 2*AUC^2/(1+AUC)
    1/(n*m)*(AUC*(1-AUC) + n*(Q1-AUC^2) + m*(Q2-AUC^2) - (Q1 + Q2 - 2*AUC^2))
  }
  
  if(is.null(n)){
    zalpha <- qnorm(1-sig.level)
    zbeta <- qnorm(power)
    fun.N <- function(N, AUC, delta, zalpha, zbeta, prev){
      Varfun(N = N, AUC = AUC, prev = prev)*(zalpha + zbeta)^2 - delta^2
    }
    n <- uniroot(fun.N, lower = 1, upper = NMAX, AUC = AUC, delta = delta, 
                 zalpha = zalpha, zbeta = zbeta, prev = prev)$root
  }else if(is.null(delta)){
    zalpha <- qnorm(1-sig.level)
    zbeta <- qnorm(power)
    fun.delta <- function(delta, N, AUC, zalpha, zbeta, prev){
      Varfun(N = N, AUC = AUC, prev = prev)*(zalpha + zbeta)^2 - delta^2
    }
    delta <- uniroot(fun.delta, lower = 1e-10, upper = AUC-1e-10, N = n, 
                     AUC = AUC, zalpha = zalpha, zbeta = zbeta, prev = prev)$root
  }else if(is.null(power)){
    zalpha <- qnorm(1-sig.level)
    fun.power <- function(power, N, AUC, delta, zalpha, prev){
      zbeta <- qnorm(power)
      Varfun(N = N, AUC = AUC, prev = prev)*(zalpha + zbeta)^2 - delta^2
    }
    power <- uniroot(fun.power, lower = 1e-3, upper = 1-1e-10, N = n, AUC = AUC, 
                     delta = delta, zalpha = zalpha, prev = prev)$root
  }else if(is.null(sig.level)){
    zbeta <- qnorm(power)
    fun.sig.level <- function(sig.level, N, AUC, delta, zbeta, prev){
      zalpha <- qnorm(1-sig.level)
      Varfun(N = N, AUC = AUC, prev = prev)*(zalpha + zbeta)^2 - delta^2
    }
    sig.level <- uniroot(fun.sig.level, lower = 1e-3, upper = 1-1e-3, N = n, 
                         AUC = AUC, delta = delta, zbeta = zbeta, prev = prev)$root
  }else stop("internal error")
  
  METHOD <- "Sample size calculation for AUC confidence interval"
  NOTE <- "n is number of cases, n1 is number of controls"
  structure(list(AUC = AUC, n = prev*n, n1 = (1-prev)*n, delta = delta, 
                 sig.level = sig.level, power = power, prev = prev, 
                 note = NOTE, method = METHOD), 
            class = "power.htest")  
}
```




## Расчёт объёма выборки под требуемые чувствительность или специфичность

### 1. Постановка задачи

При валидации алгоритмов бинарной классификации в лучевой диагностике необходимо доказать, что показатели чувствительности (Se) и специфичности (Sp) достигают клинически значимых пороговых значений. В отличие от комплексных метрик (AUC, F1-мера), чувствительность и специфичность представляют собой **пропорции бинарных исходов** — доли правильно классифицированных объектов внутри каждого из двух классов. Соответственно, задача планирования размера выборки сводится к оценке необходимого числа наблюдений для достижения заданной точности оценки пропорции при контроле ошибок I и II рода.

### 2. Параметры и обозначения

| Обозначение | Описание |
|-------------|----------|
| $p$ | Ожидаемое значение пропорции (чувствительность или специфичность) |
| $p_0$ | Пороговое значение пропорции (нижняя граница клинической значимости) |
| $\delta = p - p_0$ | Величина эффекта |
| $\alpha$ | Уровень значимости (допустимая вероятность ошибки I рода) |
| $1-\beta$ | Статистическая мощность (вероятность обнаружения эффекта) |
| $\varepsilon$ | Абсолютная величина систематической ошибки |
| $Z_{\alpha}$ | Квантиль стандартного нормального распределения для уровня $\alpha$ |
| $Z_{\beta/2}$ | Квантиль стандартного нормального распределения для мощности $1-\beta$ |
| $N$ | Общий размер выборки |
| $n$ | Размер подвыборки для оценки конкретной пропорции |

### 3. Статистические гипотезы

Для каждой из пропорций (чувствительности и специфичности) проверяется односторонняя альтернатива о превосходстве над пороговым значением:

\[
H_0: p = p_0 \quad \text{против} \quad H_1: p = p_1 > p_0
\]

где $p_1$ — целевое значение пропорции, $p_0$ — минимально допустимое значение.

### 4. Метод расчёта

Расчёт размера выборки для оценки пропорции при бинарной классификации выполняется в соответствии с **Приложением Б ГОСТ Р 71738—2024** «Расчёт размера набора данных» [1]. Для задачи оценки одной пропорции с заданной точностью применяется **формула Б.1**, основанная на нормальной аппроксимации биномиального распределения.

### 5. Формула Б.1

Необходимый размер выборки $n$ для оценки пропорции рассчитывается по формуле:

\[
n = \frac{(Z_{\alpha} + Z_{\beta/2})^2 \cdot p(1-p)}{(\delta - |\varepsilon|)^2}
\tag{Б.1}
\]

где:
- $Z_{\alpha}$ — значение нормированной случайной величины, соответствующее уровню значимости $\alpha$ (односторонний тест);
- $Z_{\beta/2}$ — значение нормированной случайной величины, соответствующее уровню ошибки II рода;
- $p$ — вероятность события, которое необходимо оценить (ожидаемая чувствительность или специфичность);
- $\delta$ — прогнозируемая погрешность (точность) оценивания — полуширина доверительного интервала;
- $\varepsilon$ — абсолютная величина систематической ошибки.

### 6. Учёт распространённости таргетного класса

При бинарной классификации чувствительность и специфичность оцениваются на **разных подвыборках**:

| Показатель | Подвыборка | Расчёт общего размера |
|------------|-----------|----------------------|
| Чувствительность ($Se$) | Положительный класс (больные) | $N_{Se} = \dfrac{n}{prev}$ |
| Специфичность ($Sp$) | Отрицательный класс (здоровые) | $N_{Sp} = \dfrac{n}{1-prev}$ |

где $prev$ — распространённость положительного класса в популяции.

**Итоговый размер выборки** определяется по **более требовательному показателю**:

\[
N = \max(N_{Se}, N_{Sp})
\]

### 7. Уравнение мощности

При $\varepsilon = 0$ (отсутствие систематической ошибки) формула (Б.1) упрощается к классическому виду уравнения мощности для пропорции:

\[
\delta = (Z_{\alpha} + Z_{\beta/2}) \cdot \sqrt{\frac{p(1-p)}{n}}
\]

или, выраженное относительно общего размера выборки $N$ с учётом распространённости:

\[
\delta^2 = (Z_{\alpha} + Z_{\beta/2})^2 \cdot \frac{p(1-p)}{prev \cdot N}
\]

### 8. Численное решение

Общий размер выборки $N$ находится аналитически из формулы (Б.1) с последующим округлением вверх до целого числа. После определения $N$ рассчитываются:

\[
n_1 = prev \cdot N \quad \text{(число случаев — положительный класс)}
\]

\[
n_0 = (1-prev) \cdot N \quad \text{(число контролей — отрицательный класс)}
\]

### 9. Примечание

> **Примечание.** При одновременной оценке двух пропорций (чувствительности и специфичности) с совместным контролем ошибок I рода рекомендуется применять **поправку Бонферрони**: уровень значимости для каждого теста устанавливается равным $\alpha/2$. В данном случае $Z_{\alpha/2}$ заменяет $Z_{\alpha}$ в формуле (Б.1), что приводит к консервативной (большей) оценке необходимого объёма выборки.

### 10. Литература

1. **ГОСТ Р 71738—2024** Системы искусственного интеллекта в лучевой диагностике. Алгоритмы анализа медицинских изображений. Методы испытаний на способность и устойчивость работы с разнородными данными. — Москва: Росстандарт, 2024. — Приложение Б (справочное): Расчёт размера набора данных.


```
# --- Параметры ---
p_expected <- 0.8        # ожидаемая чувствительность/специфичность
delta <- 0.08             # предельная ошибка выборки
alpha <- 0.05             # ошибка I рода
beta <- 0.20              # ошибка II рода
prevalence <- 0.30        # распространенность положительного класса
epsilon <- 0              # систематическая ошибка

# --- Квантили ---
z_alpha <- qnorm(1 - alpha)      # 1.645
z_beta <- qnorm(1 - beta/2)      # 1.282

# --- Формула Б.1 ---
n <- ((z_alpha + z_beta)^2 * p_expected * (1 - p_expected)) / (delta - abs(epsilon))^2
n <- ceiling(n)  # округление вверх

# --- Учёт распространённости для чувствительности ---
N_sens <- ceiling(n / prevalence)

# --- Учёт распространённости для специфичности ---
N_spec <- ceiling(n / (1 - prevalence))

# --- Итог ---
N_total <- max(N_sens, N_spec)

cat("Размер выборки для точечной оценки (n):", n, "\n")
cat("Полный размер для чувствительности:", N_sens, "\n")
cat("Полный размер для специфичности:", N_spec, "\n")
cat("Итоговый размер выборки:", N_total, "\n")

```
